# 共同交通票券設計

## 目標

在交通預訂中，讓使用者可新增「共同票券」，以一個網址或一組圖片／PDF 供所有受邀旅伴出示。

## 資料規則

- `personalTickets` 的每張票券新增 `visibility`：`personal` 或 `shared`。
- 新建立的個人票券預設為 `personal`，且仍必須選擇持有人才能儲存。
- `shared` 不使用持有人欄位，所有已登入且屬於此共享旅程的成員都可看見。
- 舊資料沒有 `visibility` 時一律正規化為 `personal`；空持有人維持只有建立者可見。

## 顯示與行程

- 共同票券會在預訂卡、今日快速取用與交通行程連結卡顯示並可開啟。
- 個人票券只會顯示給該持有人；建立者可管理／檢視全部。
- 共同票券附件沿用 `personal-ticket` 儲存位置與開啟流程，不複製到共同預訂附件。

## 相容與限制

- 不調整 Supabase schema，也不新增套件。
- 舊未指定持有人的票券不可因本次改動公開。
