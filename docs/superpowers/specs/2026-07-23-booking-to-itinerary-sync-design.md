# 預訂自動帶入行程設計規格

## 目標

新增或編輯交通、餐廳、景點票券、活動預訂時，自動在相同日期建立或更新一張行程卡，避免重複填寫共同資訊。

## 連結與同步

- 自動建立的行程項目新增 `sourceBookingId`，指向原預訂。
- 預訂儲存時，以 `sourceBookingId` 找到既有項目後更新；若日期變更，移至新日期對應 Day；不存在才建立。
- 同步欄位：時間、名稱、預訂類型、地點／路線、預訂代碼、預訂備註與共用附件。
- 行程項目的 `content`、`attractionIntro` 與自行上傳的行程附件保留給使用者補寫，不由預訂覆蓋。
- 自動帶入的來源摘要放在 `bookingSourceSummary`，與使用者自行的 `note` 分開，避免覆寫手動內容。
- 預訂日期不屬於旅程 Day 時，不建立行程卡並顯示提示。

## 類型對應

- 交通 → 行程交通；以預訂路線、班次與出發時間建立第一段交通。
- 餐廳 → 行程餐廳。
- 景點票券 → 行程景點。
- 活動 → 行程其他。
- 住宿不自動建立，避免跨多天重複。

## 圖片與票券

- 行程卡以連結方式顯示預訂的共用圖片，不複製附件或 Storage 檔案。
- 個人票券、個人票券網址與個人票券附件絕不帶入行程卡。
- 行程項目自有圖片仍可由使用者手動新增。

## 刪除

- 刪除預訂時保留已建立行程卡與手動補寫內容，但解除 `sourceBookingId` 連結，避免誤刪資料。

## 驗證

- 新增餐廳預訂後，對應日期出現一張餐廳行程卡；編輯預訂不重複建立。
- 修改預訂日期後，同一張卡移至正確 Day。
- 行程卡的餐廳介紹／內容在預訂更新後仍保留。
- 行程卡可顯示共用預訂圖片，不顯示個人票券。
- 交通預訂同步成交通行程與第一段路線資訊。
