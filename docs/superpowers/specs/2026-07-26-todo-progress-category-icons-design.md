# 待辦完成進度與分類圖示設計

## 目的

讓待辦的完成進度反映使用者目前正在看的分類，並讓「預訂與票券」及支出分類的圖示可一眼辨識；既有資料與分類值不改動。

## 範圍

### 1. 依目前選取待辦分類計算完成進度

- 「完成進度」只統計目前選取的待辦分類，不再把所有分類混在一起計算。
- 使用者切換分類後，圓環百分比、完成數、進行中數與待完成數都立即切換為該分類的結果。
- 選取「全部」時，才統計全部待辦。

### 2. 圓環內容置中

- 圓環中央的百分比文字在水平與垂直方向都置中。
- 百分比下方的「已完成數 / 總數」也置中，且在不同百分比位數下不偏移。

### 3. 預訂與支出分類使用直覺 emoji

「預訂與票券」分類按鈕、預訂卡片與支出卡片使用同一套可辨識圖示，並保留既有文字名稱：

| 分類 | 顯示圖示 |
| --- | --- |
| 全部 | ☰ |
| 票券 | 🎟️ |
| 交通 | 🚆 |
| 住宿 | 🛏️ |
| 餐廳 | 🍽️ |

未列出的既有分類（例如其他）保留原本的文字，搭配可辨識的「其他」圖示即可；不需要強制改成上述五種分類。

## 資料流

1. 使用者選取待辦分類。
2. 介面以選取分類篩出待辦；若是「全部」，保留所有待辦。
3. 由篩選後的待辦計算完成、進行中、待完成與完成百分比。
4. 圓環與圖例使用同一份計算結果渲染，避免數字不一致。
5. 預訂與票券畫面的分類按鈕、預訂卡片與支出畫面，只在顯示層將既有分類值對應為 emoji；篩選條件與儲存的分類值維持原樣。
6. 預訂資料本身不會被修改、搬移或重新分類；圖示只影響畫面呈現。

## 驗收條件

- 切換每個待辦分類時，完成百分比與三種狀態筆數只反映該分類。
- 選取「全部」時，完成進度反映全部待辦。
- 0%、100% 與任意兩位數百分比時，百分比及「已完成數 / 總數」都在圓環正中央。
- 預訂與票券分類按鈕可看見「全部 ☰、票券 🎟️、交通 🚆、住宿 🛏️、餐廳 🍽️」及各自的文字名稱。
- 預訂卡片與支出卡片能看見和分類對應的 emoji 與分類文字。
- 未列出的分類仍會顯示原本名稱與可辨識的其他圖示，不會消失或歸入錯誤分類。
- 既有預訂、支出、待辦、分類篩選與雲端同步資料不需要搬移或重寫，且原本分類結果不變。

## 非目標

- 不新增或刪除任何待辦／預訂／支出分類。
- 不改變待辦的私人／共享權限、同步邏輯或資料庫結構。
- 不改變預訂或支出分類的內部儲存值、篩選規則或預訂資料，只更新畫面上的圖示呈現。
- 不調整完成進度以外的待辦排序或狀態規則。
